# Working specs

This directory holds in-flight issue-cycle specs used by `jaunder-develop` to
derive cycle state from `issue-<N>` filenames. Commit approved specs before
implementation. After conformance review, capture enduring contracts in current
docs/ADRs and delete completed specs and outlines in a final cleanup commit.
Their history remains in Git. See
[Artifact lifecycle](../../../CONTRIBUTING.md#artifact-lifecycle).

Live design drafts retained here for unshipped work:

- `2026-06-16-emacs-blogging-frontend-design.md` — Emacs blogging frontend epic
  design.
- `2026-06-19-content-visibility-layer-c-design.md` — Content Visibility Layer C
  design.

Keep these drafts until their work lands or an explicit decision retires them.
