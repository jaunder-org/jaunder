# Issue #2049: update `url` to 2.5.9 for RUSTSEC-2026-0592

## Problem

`cargo deny check advisories` fails on every checkout, `main` included, on
RUSTSEC-2026-0592. In `url` 2.5.8 and earlier, `Url::origin()` recurses once per
nested `blob:` prefix with no depth limit, so it can overflow the stack and
abort the process. The pre-push gate therefore refuses every push.

`url 2.5.8` is locked in `Cargo.lock` and `tools/Cargo.lock`. `xtask/Cargo.lock`
does not resolve `url`. These manifests declare a `url` requirement:

- the root `Cargo.toml` (the workspace floor), with `"2.5.8"`;
- `tools/host-proof/Cargo.toml`, with `"2.5.8"`;
- `tools/qualification/Cargo.toml`, with `"2.5.8"`;
- `tools/repository-policy/Cargo.toml`, with `"2"`.

`tools/` has no workspace dependency table, so each of its crates declares its
own requirement.

## Exposure

Our code calls `url::Url::origin()` at two non-test call sites. The other
`.origin()` calls in `theme_thumbnail.rs` go to `PreviewServer::origin()`, which
returns a `&str`. Nothing calls `url::quirks::origin`.

- **`web/src/app/route_policy.rs` (`PrivateDestination::parse`).** It requires a
  value that starts with `/` and not `//`, then joins it onto
  `https://jaunder.invalid`. The result always has the `https` scheme and never
  `blob:`, so this site is not exposed.
- **`server/src/commands/theme_thumbnail.rs` (`preview_origin_allowed`).** It
  parses every request URL that headless Chromium pauses on. Those URLs can come
  from a theme repository's CSS. A `blob:` request reaching this check is
  unverified. If one did, the overflow would abort only that operator's
  theme-thumbnail command, not the server.

The bump closes the second site regardless. No code changes.

## Change

1. Set every `url` requirement listed above to `"2.5.9"`. This includes the
   loose `"2"`, so that no manifest admits a vulnerable release.
2. Run `cargo update -p url` in the root workspace and in `tools/`. In the root
   workspace this moves `url` 2.5.8 → 2.5.9 and `form_urlencoded` 1.2.2 → 1.2.3.
   Accept only the edges cargo re-resolves for this update.

`url` 2.5.9 changes one behavior: a `blob:` URL whose inner scheme is not
`http`, `https` or `file` now has an opaque origin. Neither call site above can
produce such a URL, so neither is affected.

## Acceptance

- Every lockfile that resolves `url` locks 2.5.9 or later.
- Every manifest that declares `url` requires at least 2.5.9.
- `cargo deny check advisories` passes with no new ignore.
- The full local verify passes, run through the pre-push gate.
